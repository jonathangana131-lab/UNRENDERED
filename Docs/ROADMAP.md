# Roadmap

Order is based on dependency and rewrite prevention, not visual excitement.

## Phase 0 — Production foundation
- Rojo/Rokit toolchain and CI.
- strict Luau boundaries.
- stable IDs, hash/RNG streams, versions.
- project docs/swarm protocol.
- pure deterministic test harness.

Exit: reproducible source build and green CI.

## Phase 1 — Production Physics Lab
A tiny room using final contracts:
- WorldEntity identity,
- MaterialDNA minimum,
- ObjectGenome minimum,
- affordances,
- fidelity manager,
- physical chair/table/door/cart/cabinet,
- first-person physical-body shell.

Exit: small scene, no disposable systems.

## Phase 2 — Active physical human
- physical skeleton,
- pose motors,
- balance and support polygon,
- step planner/foot contacts,
- stumble/fall/bracing,
- recovery,
- reach/grip/carry,
- climb/contact interaction,
- vestibular camera and accessibility controls.

## Phase 3 — Reality kernel
- WorldId/WorldAddress/RegionId,
- first-observation lock,
- reality confidence/significance,
- generation recipes and migrations,
- floating/local origins,
- local persistence mock.

Exit: unload/recreate exact region truth.

## Phase 4 — Architecture grammar
- region intent,
- topology graph,
- structural kit,
- office/institutional starter grammar,
- dream transitions,
- seam/reconciliation contracts,
- automated world explorer.

Exit: kilometers of deterministic traversable structure.

## Phase 5 — MaterialDNA 1.0
- substrate/finish/install/history/event layers,
- curated PBR families,
- wear/scuff/moisture/repair grammar,
- acoustic + physical material linkage,
- material validation bays.

## Phase 6 — ObjectGenome / furniture factory
- construction grammars,
- procedural office chair/table/cabinet/carts,
- Blender/offline source path where imported meshes are needed,
- ProceduralModel authoring experiments,
- LOD/physics promotion,
- mechanism validation.

## Phase 7 — Atmosphere / perception
- VibeVector,
- fixture DNA/electrical circuits,
- exposure/dark adaptation,
- optical anomaly eligibility,
- room acoustics,
- meaningful 30-second-to-few-minute atmosphere drift.

## Phase 8 — Multiplayer shared-region prototype
- server-authoritative contracts,
- prediction-safe simulation partition,
- two-player consistent region generation,
- spatial interest,
- object manipulation replication,
- reconnection.

## Phase 9 — Persistent shared-world routing
- world registry,
- region authority records,
- DataStore durable deltas,
- MemoryStore transient ownership/leases,
- MessagingService coordination where appropriate,
- server/place handoff strategy,
- Entry Cohorts.

## Phase 10 — Entities
- EntityGenome anatomy,
- senses/beliefs/memory,
- utility decisions,
- physical locomotion and falls,
- ecology.

## Phase 11 — Still Life engine
- scene grammar,
- believable intent first,
- pose/contact solver,
- violation budget,
- observation behaviors,
- contact-sheet validation.

## Phase 12 — Deep world systems
- traces/evidence,
- radios/phones/intercoms,
- security cameras,
- recordings,
- settlements/reality anchors,
- humidity/water/airflow/electrical failures.

## Phase 13 — Reality anomalies
- memory contamination,
- impossible topology,
- low-confidence mutation,
- global events,
- perception anomalies,
- Reality Debt/Familiarity Debt pacing.

## Phase 14 — Scale and performance
- Parallel Luau compute workers,
- streaming/fidelity stress,
- long server soak,
- network churn,
- mobile/console/desktop quality tiers,
- memory and instance budgets.

## Phase 15 — Content maturity
Expand grammars, materials, object families, atmospheres, entities, Still Lifes, music, narrative incident families, and community-discovery systems without changing foundational contracts unnecessarily.
